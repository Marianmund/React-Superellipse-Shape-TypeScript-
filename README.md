# React Superellipse

A reusable React component library for building modern UI elements with **superellipse-based shapes**.

The project started as part of the UI development for **Panoram**, but is designed to be reusable across other React projects as well.

## Features

- Core reusable superellipse shape
- Ready-made UI elements built around the shape
- Copy-and-use components such as buttons
- Customizable styling and sizing
- Designed for React projects
- Built to be easily extended with additional components

## Components

### Basic Superellipse

The fundamental shape of the library.

It can be used as a building block for custom UI elements, containers, cards, backgrounds, and other interfaces.

### Buttons

Pre-built buttons using the superellipse shape.

They are designed to be copied into a project and customized rather than requiring the entire component library.

More components will be added over time.
